## Quick Start

### Prerequisites
* **Python 3.x**
* **Jupyter Notebook** or **JupyterLab** *(or Google Colab / VS Code)*

### Running the Notebooks
1. Clone this repository:
   ```bash
   git clone [https://github.com](https://github.com/hanange39/stanford-cs229-summer2026.git)
   ```
2. Navigate to the repository folder:
   ```bash
   cd stanford-cs229-summer2026
   ```
3. Install common dependencies used across assignments:
   ```bash
   pip install pandas numpy matplotlib scikit-learn scipy
   ```
4. Launch Jupyter Notebook and open any assignment folder:
   ```bash
   jupyter notebook
   ```
